    How your key is stored
    • The key is encrypted (AES-GCM) with a key generated by your browser that can't be exported, and stored in this site's IndexedDB. It is never put in localStorage, cookies, or the URL.
    • This protects against someone copying the stored data off your disk, and against the key leaking into a browser sync or backup in readable form.
    • It does not protect against malicious code running on this page, or against someone who can use this browser profile while it's unlocked: both can ask the browser to decrypt it.
    • The key is only ever sent to api.guildwars2.com. This site has no server of its own.
    • Create a dedicated key with only the permissions you need at account.arena.net/applications, and delete it there when you're done. No permission lets a key spend gold or gems, but a key can read your inventory and trading post activity.
    • "Forget key" deletes it from this browser. Cached item and recipe definitions are kept separately.
