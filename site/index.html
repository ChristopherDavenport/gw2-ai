GW2 account report for AI

Paste a Guild Wars 2 API key, pick what to include, and get a markdown summary of your account to give to an AI assistant. Everything runs in this page: your key is sent only to api.guildwars2.com.

1. API key

Create one at account.arena.net/applications. It stays in this browser and is only sent to api.guildwars2.com.
